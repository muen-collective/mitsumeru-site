Canvas backgrounds

Four dependency-free background effects, ported from the Kinetic Particle Scenes Framer previews. Each one is a single module you drop behind your content.

Spherical Arcs A sphere of twisted latitude arcs with travelling light and a pointer-lit cap. Spatial Wireframe A drifting point cloud rebuilt as a spanning tree each frame. Nodes are draggable. ASCII Water Reveal A wave simulation that draws its surface as ASCII glyphs. Move the pointer to stir it. Quick Scan Button A bordered button with a scanning rule and a per-character text reveal on hover.
01

Wireframe

Sixteen points, held together by the shortest lines between them. The edge set is rebuilt every frame, so the shape is only ever whatever the space currently allows.

02

Polygon

Twelve corners, thirty edges, twenty faces. A regular icosahedron has nothing left to remove and nothing left to add — back faces fall away into the dark.

03

Sphere

The same volume, smoothed past the point where any corner survives. Twenty arcs run pole to pole, each one twisted by its own latitude.
