Wireframe

Sixteen points, held together by the shortest lines between them. The edge set is rebuilt every frame, so the shape is only ever whatever the space currently allows.

02

Polygon

Twelve corners, thirty edges, twenty faces. A regular icosahedron has nothing left to remove and nothing left to add — back faces fall away into the dark.

03

Sphere

The same volume, smoothed past the point where any corner survives. Twenty arcs run pole to pole, each one twisted by its own latitude.
