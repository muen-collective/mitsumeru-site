Spatial Wireframe

A drifting cloud of points wired together as a minimum spanning tree. The tree rebuilds every frame as the points swim, with a discount on edges that already exist so the shape holds together instead of flickering.

Drag any node to move it. The offset you leave behind sticks while the rest of the cloud keeps drifting. Move the pointer near a node to light it up.

Drop-in usage: createSpatialWireframe(el, { settings }) — same handle as the arcs: stop() and a live settings object.
